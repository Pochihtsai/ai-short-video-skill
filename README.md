# ai-short-video skill

讓 Claude（桌面版的 Code 分頁）用 HyperFrames 做中文或英文的短片，直式（Reels、Shorts、TikTok）或橫式（YouTube、簡報）都可以：寫故事線、配音、動畫、字幕、依內容找免費可商用的配樂，最後輸出 MP4。

- **下載安裝包**：https://github.com/Pochihtsai/ai-short-video-skill/releases/latest/download/ai-short-video-setup.zip
- **安裝步驟**：看 [安裝說明.md](安裝說明.md)
- Mac、Windows 共用同一份安裝包，Claude 會依你的電腦自動選對的設定方式
- 限個人使用；配音用的 edge-tts 會把台詞送到微軟的線上服務
