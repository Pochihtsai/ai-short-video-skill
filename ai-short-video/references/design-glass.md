# 影片設計規範：淺色玻璃風（直式、橫式通用）

風格重點：冷白灰底、兩團金／深藍綠柔光、半透明白卡片＋柔和陰影、圓角六角形、金色為主、深藍綠標第二重點。

## 顏色

| 角色 | 色碼 | 用途 |
|---|---|---|
| 背景 | `#F6F7F8` → `#EEF1F3` 直向漸層 | 全片底色 |
| 斜向光帶 | 118°，`rgba(255,255,255,.6)` 在 50% | 疊在底色上 |
| 金色柔光 | `rgba(222,164,18,.30)` → `.11` → 透明 | 右側中段的大橢圓 |
| 深藍綠柔光 | `rgba(18,128,172,.26)` → `.09` → 透明 | 左下偏中的大橢圓 |
| 內文 | `#22303A` | 標題、字幕 |
| 次要文字 | `#46545E` | 說明、標籤 |
| 品牌金 | `#AA8421` | 線條、圖示 |
| 深金 | `#8A6A1A` | 小標、強調字 |
| 最深金 | `#6B5012` | 結論、重點標題字 |
| 深藍綠 | `#1F4E63`（亮端 `#3F7C96`） | 第二重點 |
| 退回／錯誤 | `#C2412D` | 只用在 ✕ |

金色面積小但最搶眼，深藍綠用來穩住畫面。每一幕只有一個金色重點。

## 元件

- **卡片**：`rgba(255,255,255,.86)`、1.5px 白色細邊、圓角 28px。陰影：`inset 0 2px 0 rgba(255,255,255,.9), 0 2px 4px rgba(28,42,52,.05), 0 24px 60px -16px rgba(28,42,52,.18)`
- **圓角六角形**：用 glass.css 的 path（每個轉角用二次曲線切圓，內側一道白色細線當光澤）
  - 金：`#B8922F` → `#7E5F14`
  - 深藍綠：`#4A86A0` → `#1F4E63`
  - 線框：白 70% 填色＋品牌金 5px 外框
- **agent**：畫成圓角六角形，裡面是一筆畫的臉（兩點眼睛＋一道弧線嘴）
  - 主管：金色
  - 驗收員：深藍綠
  - 執行者：白色玻璃線框
- **圖示**：一筆畫線條、轉折用圓角，每個圖示斷開一處，斷口中間放一個點
- **場景標籤**：每一幕標題上方放「短金線＋STEP 0X（英文全大寫、寬字距、小字）」，下面接標題

## 字

- 字型：中文 Mac 用蘋方-繁、Windows 用微軟正黑體，寫在同一個 `@font-face` 的多個 `local()` 裡（見 templates/example_A_v3.html）；英文用內建的 Inter
- **字級適度、不要太大太滿**：標題和字幕的字級照 SKILL.md「語言與方向」的表；直式的標籤 30px、卡片內文 38–42px，橫式依比例調整
- **粗體少用**：只給標題的關鍵字、卡片小標和深色底上的白字，其他靠字級與顏色區分
- 主文字和副標之間要拉開，版面要舒展

## 字幕

- 白色玻璃膠囊：`rgba(255,255,255,.86)`＋白邊＋柔和陰影，內文 `#22303A`
- 位置照 SKILL.md「語言與方向」的表（直式和橫式不同）

## 動態

- 柔光慢慢呼吸、漂移：只動 scale、位置和透明度，週期 11s／14s 錯開
- 進場以淡入加小位移為主，動作輕、不閃。不用閃光、發光、粒子
- 每一幕的進場方式要有變化，不要每個元素都「淡入＋往上滑」

## 安全區

- 直式、橫式的數字都在 SKILL.md「語言與方向」的表
- 橫式的柔光位置：金色放右上、深藍綠放左下，範例見 templates/example_landscape_en.html

## 聲音（A 版的實例）
