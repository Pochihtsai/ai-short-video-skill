# 公司風格參考：淺色玻璃風（直式、橫式通用）

什麼時候用：使用者說要「公司風格」，或內容是公司內部說明、而且這個風格適合時才用。它不是預設；第 3 關仍由 Claude 依內容設計兩種風格，這份只是其中一個可能的方向。下面的數字是參考值，可以依內容調整。

風格重點：冷白灰底、兩團金／深藍綠柔光、半透明白卡片＋柔和陰影、圓角六角形、金色為主、深藍綠標第二重點。

## 顏色

| 角色 | 色碼 | 用途 |
|---|---|---|
| 背景 | `#F6F7F8` → `#EEF1F3` 直向漸層 | 全片底色 |
| 斜向光帶 | 118°，`rgba(255,255,255,.6)` 在 50% | 疊在底色上 |
| 金色柔光 | `rgba(222,164,18,.30)` → `.11` → 透明 | 大橢圓 |
| 深藍綠柔光 | `rgba(18,128,172,.26)` → `.09` → 透明 | 大橢圓 |
| 內文 | `#22303A` | 標題、字幕 |
| 次要文字 | `#46545E` | 說明、標籤 |
| 品牌金 | `#AA8421` | 線條、圖示 |
| 深金 | `#8A6A1A` | 小標、強調字 |
| 最深金 | `#6B5012` | 結論、重點標題字 |
| 深藍綠 | `#1F4E63`（亮端 `#3F7C96`） | 第二重點 |
| 退回／錯誤 | `#C2412D` | 錯誤、退回 |

金色面積小但最搶眼，留給最重要的地方；深藍綠用來穩住畫面。

## 元件

- **卡片**：`rgba(255,255,255,.86)`、1.5px 白色細邊、圓角 28px。陰影：`inset 0 2px 0 rgba(255,255,255,.9), 0 2px 4px rgba(28,42,52,.05), 0 24px 60px -16px rgba(28,42,52,.18)`
- **圓角六角形**：每個轉角用二次曲線切圓，內側一道白色細線當光澤
  - 金：`#B8922F` → `#7E5F14`
  - 深藍綠：`#4A86A0` → `#1F4E63`
  - 線框：白 70% 填色＋品牌金 5px 外框
- **圖示**：一筆畫線條、轉折用圓角

## 字

- 字型設定照 SKILL.md「字型」（中文 Mac 蘋方、Windows 微軟正黑體，英文 Inter）
- 字級適度、不要太大太滿；粗體少用，只給關鍵字和小標
- 主文字和副標之間要拉開，版面要舒展

## 字幕

- 白色玻璃膠囊：`rgba(255,255,255,.86)`＋白邊＋柔和陰影，內文 `#22303A`
- 位置照 SKILL.md「語言與方向」的表

## 動態

- 柔光可以慢慢呼吸、漂移（只動 scale、位置和透明度，兩團週期錯開）
- 這個風格偏安靜，動作預設輕一點；內容需要時可以用更強的動作，但不要為了熱鬧加閃光、粒子
- 每一幕的進場方式要有變化

## 橫式

- 柔光可以金色放右上、深藍綠放左下，範例見 templates/example_landscape_en.html
